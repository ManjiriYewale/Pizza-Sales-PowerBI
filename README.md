# Pizza-Sales-PowerBI
# 🍕 Pizza Sales Report (Power BI)

This repository contains a Power BI project that analyzes pizza sales data.  
The report provides clear insights into sales performance, customer behavior, and product trends.

---

## 📂 Files Included
- **Pizza_Sales.pbit** → Power BI Template file (report design without data).
- **Pizza_Sales.pbix** → Full Power BI report file (if included).
- **/screenshots/** → Dashboard screenshots (optional).

---

## 📊 Key Insights from the Report
- Total revenue generated and overall performance.
- Daily and weekly order trends.
- Average order value (AOV).
- Top-selling pizzas and their contribution to sales.
- Interactive visuals for exploring different dimensions of sales.

---

## 🚀 How to Open the Report
1. Download the `.pbit` (or `.pbix`) file from this repository.  
2. Open the file using **Power BI Desktop**.  
3. If using `.pbit`, connect your own data source when prompted.  

---

## 🛠️ Tools Used
- **Power BI Desktop** → for report building and data visualization.  
- **Power Query (M language)** → for data transformation.  
- **DAX (Data Analysis Expressions)** → for calculated measures.
